# Vehicle Dynamics Simulator

A vehicle dynamics simulator written in Python.

## Goals

This project is a long-term exploration of vehicle physics inspired by games such as Forza Motorsport and Gran Turismo.

Current features:

- Engine torque generation
- Gearbox
- Open differential
- Rear-wheel drive drivetrain
- Tyre grip model
- Physics integration
- Basic acceleration simulation
- Engine RPM
- Torque curves
- Steering (work in progress)
- Telemetry
 
## Planned features

- Automatic and manual gearboxes
- Suspension
- Weight transfer
- Aerodynamic drag
- REST API
- Visualisation
